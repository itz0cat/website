Installation Instructions

  1. Ensure you have Fabric Loader ≥ 0.16.x installed for your targeted Minecraft version (1.21.x).
  2. Place the required Fabric API JAR into your .minecraft/mods folder (or PojavLauncher mods folder).
  3. Download the mod JARs from above and place them in the same mods/ directory.
  4. Launch Minecraft, connect to your server, and activate your license using /cat key <your-key> or /catflip license <your-key>.
