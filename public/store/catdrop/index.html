How It Works

How CatDrop Works (Autonomous Macro Routine)

Engineered with a robust 9-stage state machine that interacts cleanly with the server without anti-cheat kicks.

1

License Verification & Initialization (START)

CatDrop authenticates your license with CatCore. If valid, it snapshots your current inventory layout and verifies your player state before triggering any server interactions.

2

Inventory Capacity Check (CHECK_INV)

Inspects inventory slots 9 through 44. If already packed with 36 stacks of bones, CatDrop skips the shop stage completely and transitions immediately to dropping items to save time.

3

Safe /shop Bulk Purchasing Routine (OPEN_SHOP → BUY_STACK)

Sends /shop with an anti-spam cooldown, clicks Mob Drops (slot 16), selects Bone, switches to Chest bulk mode, and purchases 36x bone stacks in a single clean interaction before closing the GUI.

4

High-Speed Auto-Drop Loop (DROP_BONES)

Iterates through player inventory slots 9-44 and fires SlotActionType.THROW packets with humanized, configurable tick pacing (default 2 ticks / 100ms) until every bone stack is dropped.

5

Autonomous Continuous Loop

Once inventory is cleared, CatDrop safely pauses for the configured cooldown period and loops back to Step 2, running 24/7 without manual intervention.
